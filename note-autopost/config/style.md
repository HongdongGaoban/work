# 文体・トーン・NG表現

詳細な書き方の指針はリポジトリ直下の `note_writing_manual.md` を参照。

## トーン
- です・ます調。読者に語りかける、等身大の書き方
- 体験・具体例を先に、一般論は後に
- 1 段落は 2〜4 文程度。スマホで読みやすい長さに

## 形式（DESIGN.md §5.3）
- 見出しは `##` と `###` のみ
- 表は使わず箇条書きに置き換える
- リストの入れ子は使わない

## NG ワード
checks が機械的に検出する。1 行 1 語、`- ` で始める。

- いかがでしたか
- いかがでしたでしょうか
- 結論から言うと
- 〜と言っても過言ではありません
- 魅力に迫ります
